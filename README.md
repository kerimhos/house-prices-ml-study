# Ames Housing Fiyat Tahmini
Bu projede, Ames Housing veri setini kullanarak ev fiyatlarını tahmin eden bir PyTorch sinir ağı geliştirdim.

## Notlar
- Veri ön işleme ve model tasarımı için PyTorch ve Scikit-learn kullandım.
- Kod yazımı ve hata ayıklama sürecinde yapay zeka bana rehberlik etti, özellikle veri ölçeklendirme ve PyTorch tensor’larını anlama konularında.

Veri seti linki: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/overview
